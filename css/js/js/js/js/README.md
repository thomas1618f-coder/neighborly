# Neighborly

**Help nearby. Feel good.**

A polished community mutual-aid web app prototype focused on:

- **Food sharing** – excess meals, produce, pantry items
- **Tool lending** – drills, ladders, kitchen gear, etc.
- **Volunteer matching** – time, skills, helping hands
- **Item donations** – clothes, books, furniture
- **Requests** – ask for what you need
- **Impact tracking** – see the good your neighborhood creates

## Design principles (Apple-inspired)

- **Clarity & purpose** – every screen has a clear primary action
- **Agency** – people stay in control; easy to post, claim, or cancel
- **Feedback** – subtle visual + audio responses on every meaningful action
- **Familiarity** – card-based layouts, bottom tab bar, bottom sheets
- **Delight** – soft animations, gentle chimes, recognition without pressure
- **Responsibility** – privacy-minded, trust signals (verified, ratings)

## Visual & sound design

- Clean typography (Inter / system fonts), rounded cards, soft shadows
- Dynamic light / dark mode that respects system preference
- Micro-interactions (scale on press, smooth sheet transitions)
- Purpose-built UI sounds via Web Audio API:
  - Soft click for navigation
  - Gentle two-note success chime (post / claim)
  - Quiet whoosh for sheets opening

---

## How to run

Open `index.html` in any modern browser, or serve the folder locally.
